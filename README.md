# AI Trading Signal Analyzer Pro

A Python desktop application built with PySide6 for analyzing financial markets using technical indicators and AI-assisted insights.

## Features (Planned)

- Professional desktop interface
- Dashboard
- Technical indicators (RSI, EMA, MACD)
- Candlestick charts
- Trading signals
- SQLite trade journal
- Export to CSV
- AI-assisted analysis

## Technologies

- Python
- PySide6
- Git
- SQLite
